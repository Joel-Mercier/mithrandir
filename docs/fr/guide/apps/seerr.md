# <img src="https://cdn.jsdelivr.net/gh/selfhst/icons/png/jellyseerr.png" width="32" height="32" style="display:inline;vertical-align:middle;margin-right:8px"> Seerr

Gestionnaire de demandes multimédia pour Jellyfin — permet aux utilisateurs de demander des films et des séries TV qui sont automatiquement envoyés à Sonarr et Radarr.

| | |
| --- | --- |
| **Image** | `ghcr.io/seerr-team/seerr:latest` |
| **Interface web** | `http://your-server:5055` |
| **Chemin de configuration** | `{BASE_DIR}/seerr/app/config` |
| **Site web** | [seerr.dev](https://seerr.dev/) |
| **Code source** | [GitHub](https://github.com/seerr-team/seerr) |

## Installation

```sh
mithrandir install seerr
```

## Configuration automatique

Lorsqu'il est installé via l'assistant de configuration, Seerr est automatiquement configuré avec l'utilisateur Jellyfin, les bibliothèques Jellyfin et la configuration de Radarr & Sonarr.

## Configuration

Complétez l'assistant d'intégration et configurez vos utilisateurs, permissions et paramètres.
