# <img src="https://cdn.jsdelivr.net/gh/selfhst/icons/png/retroassembly.png" width="32" height="32" style="display:inline;vertical-align:middle;margin-right:8px"> RetroAssembly

Collection personnelle de jeux rétro dans votre navigateur. RetroAssembly amène les consoles de jeux classiques directement dans votre navigateur — NES, SNES, Genesis, GameBoy, Arcade, et plus encore. Il détecte automatiquement les jaquettes, prend en charge les sauvegardes d'état avec synchronisation, le retour en arrière du gameplay, les shaders rétro et la saisie par manette ou contrôleur virtuel à l'écran.

| | |
| --- | --- |
| **Performance** | Low — Émulation dans le navigateur, charge serveur minimale |
| **Stockage** | Medium — Stocke les ROMs, les sauvegardes d'état et les jaquettes |

## Installation

```sh
mithrandir install retroassembly
```

## Configuration

1. Ouvrez votre navigateur et accédez à `http://your-server:8001`
2. Créez un compte après avoir cliqué sur le bouton "Library"
3. Téléchargez vos fichiers ROM et commencez à jouer

## Plateformes supportées

RetroAssembly prend en charge de nombreuses consoles de jeux rétro, notamment :

- NES / Famicom
- SNES / Super Famicom
- Sega Genesis / Mega Drive
- Game Boy / Game Boy Color / Game Boy Advance
- Arcade (MAME)
- Et plus encore

## Fonctionnalités

- **Jaquettes auto-détectées** — Votre collection de jeux est affichée avec de belles pochettes
- **Sauvegardes d'état** — Sauvegardez et synchronisez votre jeu à tout moment et reprenez plus tard
- **Retour en arrière** — Certains émulateurs vous permettent de rembobiner le gameplay
- **Navigation spatiale** — Parcourez votre bibliothèque au clavier ou à la manette
- **Shaders rétro** — Améliorez votre expérience avec des effets visuels rétro
- **Contrôleur virtuel** — Jouez sur mobile avec une manette à l'écran
