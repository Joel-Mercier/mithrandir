# stop

Arrêter une application en cours d'exécution.

## Utilisation

```sh
mithrandir stop <app>
```

## Arguments

| Argument | Description |
| --- | --- |
| `app` | **Requis.** Nom de l'application à arrêter |

## Description

Arrête le conteneur Docker de l'application avec `docker compose down`.

## Remarques

- Nécessite les privilèges root
