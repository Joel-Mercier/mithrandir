# <img src="https://cdn.jsdelivr.net/gh/selfhst/icons/png/memos.png" width="32" height="32" style="display:inline;vertical-align:middle;margin-right:8px"> Memos

Lightweight self-hosted memo hub and knowledge management — capture ideas, notes, and knowledge snippets with a clean, privacy-first interface.

| | |
| --- | --- |
| **Image** | `neosmemo/memos:stable` |
| **Web UI** | `http://your-server:5230` |
| **Config path** | `{BASE_DIR}/memos/data` |
| **Website** | [usememos.com](https://usememos.com/) |
| **Source code** | [GitHub](https://github.com/usememos/memos) |

## Resource Impact

| | |
| --- | --- |
| **Performance** | Low — Lightweight memo server |
| **Storage** | Low — SQLite database for memos |

## Installation

```sh
mithrandir install memos
```

## Setup

- Open the web UI at `http://your-server:5230`
- Create your admin account on first launch
- Start capturing memos, notes, and ideas

## Features

- Markdown support with rich editing
- Tags and filters for organizing memos
- REST API for integrations
- Lightweight SQLite storage
