# Excalidraw

Virtual whiteboard for sketching — create diagrams, wireframes, and hand-drawn style illustrations collaboratively.

| | |
| --- | --- |
| **Image** | `excalidraw/excalidraw:latest` |
| **Web UI** | `http://your-server:5000` |
| **Config path** | `{BASE_DIR}/excalidraw/config` |
| **Website** | [excalidraw.com](https://excalidraw.com/) |
| **Source code** | [GitHub](https://github.com/excalidraw/excalidraw) |

## Installation

```sh
sudo mithrandir install excalidraw
```

## Setup

No additional setup required.
